# עדכוני Memora

כאן מתפרסמים עדכוני Memora למחשב ולטלפון, בלי Google Play.

Memora בודקת לבד אם יש גרסה חדשה, מורידה אותה, ובודקת את **החתימה** לפני ההתקנה. בלי חתימה תקינה של Memora הקובץ לא מותקן.

במאגר הזה אין את קוד המקור של האפליקציה ואין מפתחות חתימה. העדכונים עצמם נמצאים ב־[Releases](https://github.com/Shalom-Horvitz/memora-updates/releases).

ההתקנה הראשונה של גרסה 2.17 במחשב או 1.2.0 בטלפון היא ידנית (קובץ עדכון או APK). אחריה, עדכונים הבאים מגיעים מתוך האפליקציה.
